Prerequisite Info:
    1. The APT package supplies the following unit files and script by default:
        apt-daily.timer
        apt-daily.service

        apt-daily-upgrade.timer
        apt-daily-upgrade.service

        /usr/lib/apt/apt.systemd.daily

        The timers trigger the services which trigger the script.

    2. The unattended-upgrades package supplies the following config files:
        /etc/apt/apt.conf.d/20auto-upgrades (which must initially be generated (see /usr/share/doc/unattended-upgrades/README.md.gz) in order to enable the upgrade functionality)
        /etc/apt/apt.conf.d/50unattended-upgrades

        (As well as templates under /usr/share/unattended-upgrades/)

    3. apt-daily.service runs the apt.systemd.daily script with the "update" argument, and apt-daily-upgrade.service with the "install" argument.
       The script checks whether the relevant APT configuration options APT::Periodic::Update-Package-Lists and APT::Periodic::Unattended-Upgrade located in 20auto-upgrades are set to "1".
       If so, the script then updates the package lists using apt-get and invokes unattended-upgrade to download and install eligible upgrades.

    4. Control flow:
       apt-daily.timer         -> apt-daily.service         -> "apt.systemd.daily update"  -> "apt-get update"
       apt-daily-upgrade.timer -> apt-daily-upgrade.service -> "apt.systemd.daily install" -> unattended-upgrade


Instructions:
    1. Make sure the unattended-upgrades and debdelta packages are installed.

    2. Create a 50unattended-upgrades fragment file (e.g 51unattended-upgrades-local) and customize the following config to your needs:
        Unattended-Upgrade::Origins-Pattern {
            // Covers all the common Debian suits and components
            "origin=Debian,codename=${distro_codename},label=Debian";
            "origin=Debian,codename=${distro_codename}-updates,label=Debian";
            "origin=Debian,codename=${distro_codename}-security,label=Debian-Security";

            // Or match all
            // "origin=*";
        };

        // Runs "dpkg --force-confold --configure -a" upon unclean dpkg exit. Default = true
        Unattended-Upgrade::AutoFixInterruptedDpkg "true";

        // Split the upgrade into the smallest possible chunks so that
        // they can be interrupted with SIGTERM. This makes the upgrade
        // a bit slower but it has the benefit that shutdown while an upgrade
        // is running is possible (with a small delay)
        Unattended-Upgrade::MinimalSteps "true";

        // Remove unused automatically installed kernel-related packages
        // (kernel images, kernel headers and kernel version locked tools).
        Unattended-Upgrade::Remove-Unused-Kernel-Packages "true";

        // Automatic removal of newly unused dependencies after the upgrade
        Unattended-Upgrade::Remove-New-Unused-Dependencies "true";

        // Do automatic removal of unused packages after the upgrade
        // (equivalent to apt-get autoremove)
        Unattended-Upgrade::Remove-Unused-Dependencies "true";

        // Automatically reboot *WITHOUT CONFIRMATION* if
        //  the file /var/run/reboot-required is found after the upgrade
        Unattended-Upgrade::Automatic-Reboot "true";

        // Automatically reboot even if there are users currently logged in
        // when Unattended-Upgrade::Automatic-Reboot is set to true
        Unattended-Upgrade::Automatic-Reboot-WithUsers "false";

        // If automatic reboot is enabled and needed, reboot at the specific
        // time instead of immediately
        //  Default: "now"
        Unattended-Upgrade::Automatic-Reboot-Time "04:00";

        // Apt bandwidth limit, 100 Mbps
        Acquire::http::Dl-Limit "100000";

        // Enable logging to syslog. Default is False
        Unattended-Upgrade::SyslogEnable "true";

        // Download and install upgrades only on AC power
        // (i.e. skip or gracefully stop updates on battery)
        Unattended-Upgrade::OnlyOnACPower "false";

        // Download and install upgrades only on non-metered connection
        // (i.e. skip or gracefully stop updates on a metered connection)
        Unattended-Upgrade::Skip-Updates-On-Metered-Connections "true";

        // Verbose logging
        Unattended-Upgrade::Verbose "false";

    3. Generate the 20auto-upgrades config file by running "sudo dpkg-reconfigure unattended-upgrades" and selecting "Yes" when prompted to enable automatic updates,
       then follow the instructions outlined in step 2 to create a fragment file and customize the following config to your needs:

        // NOTE: Options set to "always" so trigger time is managed by apt-daily-upgrade.timer
        APT::Periodic::Update-Package-Lists "always";

        // Download packages (e.g using apt-get upgrade --download-only) before performing the update in order to increase robustness
        APT::Periodic::Download-Upgradeable-Packages "always";

        // Use debdelta to minimize download size by only downloading deltas
        APT::Periodic::Download-Upgradeable-Packages-Debdelta "1";

        APT::Periodic::Unattended-Upgrade "always";
        APT::Periodic::AutocleanInterval "90";
        APT::Periodic::CleanInterval "90";

    4. Edit apt-daily-upgrade.timer in order to customize the timing of the upgrades. Make sure to add "OnCalendar=" in order to clear the previous setting.
    5. Restart apt-daily-upgrade.timer and check the status to make sure no config errors are present.
    5. Run "sudo unattended-upgrade --debug --dry-run" and verify that everything's working.
    6. Reboot
